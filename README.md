# Stephen Li — Personal Website

My personal website, live at [stephenli7.github.io](https://stephenli7.github.io).

## What's on it

- **Portfolio** — work experience (Meta, Cloudflare, Good Eggs, Capital One), education (UPenn), and projects
- **Hobbies** — food, volleyball, and mountain sports with photos
- **Photos** — personal photo gallery organized by category

## Stack

- [React](https://react.dev) + [TypeScript](https://www.typescriptlang.org)
- [Vite](https://vitejs.dev) for bundling and local dev
- [Tailwind CSS](https://tailwindcss.com) for styling
- [shadcn/ui](https://ui.shadcn.com) for UI components
- [React Router](https://reactrouter.com) for client-side routing
- Deployed via [GitHub Pages](https://pages.github.com) with GitHub Actions
